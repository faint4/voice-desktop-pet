# Mint Assistant 姿态生成提示词

生成方式：Codex 内置图像生成工具，以 `master.png` 作为每次生成的身份参考与编辑目标。

所有姿态共用以下身份锁定要求：保持同一位成年女性的脸、肩长深色头发、身体比例、白色薄荷绿滚边夹克、炭灰色上衣和长裤、白色运动鞋；使用相同的正面全身比例和机位；头、双手、双脚完整可见；只改变姿势和表情；单人、真实人体结构、无道具、文字、标志或水印。

| ID | 姿态提示词摘要 |
|---|---|
| `listen` | 轻微前倾和侧头，一只手靠近耳侧，专注聆听。 |
| `think` | 一手托腮，另一只前臂自然横于腰前，平静思考。 |
| `speak` | 张口说话，一只手做开放式讲解手势。 |
| `nod` | 点头最低点，眼睛微垂，双手自然放在身前。 |
| `wave` | 右臂抬至头侧，手掌朝前，五指自然分开。 |
| `happy` | 明亮微笑，双前臂抬起，呈克制的庆祝姿态。 |
| `surprised` | 眉毛抬起、眼睛睁大、嘴微张，双手在胸前张开。 |
| `confused` | 轻微歪头、一侧眉毛抬起、一手掌心向上。 |
| `comfort` | 一手放心口，另一只手向前伸出，表达安慰。 |
| `goodbye` | 手掌向外完成挥手，身体略微转动，温和告别。 |

原始 RGB 生成结果存放于本地 `poses/`，最终项目素材为经过 U2Net 抠像的 `poses-rgba/`。
